# 케이블 단면 3D 뷰어

설계자가 확인한 케이블 단면 DXF를 3D와 IEC 60502 판정 요약으로 보여주는 뷰어.

- 게시 주소: https://claude.ai/artifact/PxqBR9SAGmAG24PMjgz39Y

## 파일

|---|---|
| `index.html` | 뷰어 본체 (게시 원본) |
| `iec-tables.json` | 규격 기준값 (IEC 60502 · 60228, 저압은 K 60502-1 부속서 A 가상 계산 표 포함). 값마다 출처와 확인 상태 |
| `규격값_확인표.csv` | 기준값 확인표. 엑셀로 열어 규격 원문과 대조 |
| `report.json` | 최근 게시한 보고 (PC 보고 화면) |

## 케이블 모델 (설계 공정)

예제 도면은 모두 지우고, 설계자가 학습한 모델만 넣는다. 모델은 `index.html`의 `MODELS`에 **설계 공정 순서 그대로** 적는다.
뷰어가 공정마다 동심원 단면을 그려 도면과 같은 경로로 판정한다.

| 버튼 | 케이블 | 주소 이름 |
|---|---|---|
| TFR-CV 1×75 | 0.6/1kV TFR-CV 1×75SQ (COMPACT) · 압축연선 · XLPE · PVC 2층 시스 | `tfrcv1x75` |

공정 항목 (없는 항목은 적지 않음): 공정명 · 자재 · 색상 · 두께(mm) · 소선(개) · 외경(mm) · 중첩 · 방향 · 피치 · 단위(개) · 단면적(mm²) · 연입률

- 외경은 그 공정까지 진행한 **총 외경**. 단면은 외경으로 그린다
- `신선` 공정은 소선(지름 · 단위)으로 보고 다음 `연선` 공정의 도체에 붙는다. `압축연선`이면 3D에 압축 도체(얕은 소선 홈 · 끝면의 압축 소선 경계)로 보인다
- 소선 수 · 피치 · 방향은 판정과 3D 꼬임에 쓰인다. 연입률이 없으면 피치로 바깥층 값을 계산해 쓴다
- 공정명은 정보 카드(층을 눌렀을 때)와 보고 화면 `상세 판정 · 설계 공정 · 연입률`에만 나온다. 3D 이름표 · 구성 목록에는 안 나온다

설계자가 게시한 보고가 있으면 맨 앞에 `최근 게시`로 나온다. 공개 사이트 첫 주소(`?c=` 없이)도 이 모델들을 보여 준다.

## 케이블별 QR

1. `미리보기.bat` → 설계 화면에서 도면 확인 → `확인 완료 · 게시`
2. 보고 화면 우상단에 그 케이블의 QR이 나온다 (`반영 중` → 1~2분 뒤 사라지면 휴대폰에서 열림)
3. QR을 누르면 크게 보기 · 링크 복사 · QR 이미지 저장

- 휴대폰 주소: `https://flowerpig4029473.github.io/cable-viewer/?c=<id>` (로그인 없이, 그 케이블 하나만)
- 처음엔 케이블과 이름만, 화면을 누르면 판정 · 구성 상세가 나온다 (3D 위 번호 · 이름 라벨은 표시 안 함)
- 같은 케이블을 고쳐 다시 게시하면 QR은 그대로, 내용만 바뀐다. 새 도면은 새 QR
- 게시 → GitHub 업로드는 `tools/publish-push.ps1`이 자동 처리 (기록: `%TEMP%\cable-viewer-publish.log`).
  `반영 안 됨`이 뜨면 `tools/GitHub_올리기.bat` 실행
- Claude 게시 페이지(claude.ai)에서 게시한 보고에는 QR이 없다 (GitHub에 올릴 수 없음)

GitHub에 올릴 때마다 `.github/workflows/pages.yml`이 공개 뷰어를 새로 만든다.

## 외형 구조 (실물 형태)

설계 화면에서 층을 누르면 정보 카드 아래 `외형 구조`에서 바꾼다. 레이어 이름 키워드로 기본값이 정해지고, 게시하면 휴대폰 화면도 같은 모양으로 보인다.

| 구성요소 | 선택 |
|---|---|
| 도체 | 원형 일반연선 · 원형 압축연선 · 선형 압축 (섹터) · 분할 압축 (밀리켄) · 단선 |
| 절연체 (선심 식별) | 식별 없음 · 마스터배치 · 잉크 인쇄 (문구 · 색) · 색별 테이프 |
| 반도전층 | 압출 · 반도전 테이프 · 색별 테이프 |
| 금속 차폐 | 테이프 (동 · 알루미늄 · 알루미늄 마일라 …) · 편조 (캐리어 · 피복률) · 선재 |
| 개재물 | PP끈 · 종이끈 · 난연 PP끈 · 압출 개재 |
| 테이프 층 | 종류 (PET · P/S · PP · 글라스 · 부직포 · 수밀 · 마이카 · 동 · 알루미늄 · 강 …), 감기 (중첩 · 맞대기 · 간격 · 종첨), 중첩률 %, 폭 mm, 방향 |
| 외장 | 금속선 (도면) · 금속 테이프 (간격 감기) · 인터록 (피치 · 깊이) |
| 금속 시스 | 평활 · 주름 (나선형) · 주름 (환형) |

레이어 이름 키워드 예: `braid` `편조`, `mylar` `마일라`, `interlock` `인터록`, `corrugated` `주름`, `종첨`, `맞대기`, `25%`(중첩률), `ink` `잉크`, `색별`, `paper` `종이`, `난연`, `glass` `글라스`, `P/S`.

## 규격 기준값 확인

기준값의 확인 상태는 세 가지.

- 원문 확인: 규격 원문과 대조 완료
- 공개자료 일치: 제조사 자료 등 공개 자료와 일치, 원문 미대조
- 원문 대조 필요: 아직 확인 안 됨

뷰어의 설계 화면에서 판정마다 쓴 기준값의 상태가 표시된다. 표시에 마우스를 올리면 출처가 보인다.

확인 절차:

1. `규격값_확인표.csv`를 엑셀로 연다.
2. 규격 원문과 대조해 `원문값`, `일치(O/X)`, `확인자`, `확인일`을 채운다.
3. 채운 파일로 `iec-tables.json`을 갱신한다. 값이 다르면 수정하고 상태를 `verified`로 바꾼다.

저압(0.6/1 · 1.8/3 kV) 기준값은 K 60502-1:2006 (IEC 60502-1:2004 번역본)과 대조해 `verified`로 표시했다. 대조한 표 · 조항은 확인표 `비고`에 있다.
번역본과 IEC 원문이 서로 다른 시스 최소 두께 규칙(16.5.3)은 `원문 대조 필요`로 남겨 두었다.

저압 판정에서 IEC 60502-1을 적용하는 방식:

- 절연 공칭 두께: 표 5 (PVC) · 표 6 (XLPE) · 표 7 (EPR). 비표준 단면적은 그 단면적이 속한 구간 값
- 시스 · 내부 피복 · 외장 두께: 도면 실측이 아니라 **부속서 A 가상 직경**(dL → Dc → Df → …, 단계마다 0.1 mm 수치맺음)으로 표를 찾는다.
  계산할 수 없는 층(금속 시스 · 테이프 차폐 등)이 있으면 도면 실측 직경을 쓰고 그 이유를 표시한다
- 여러 층으로 압출한 외부 시스(예: PVC 2층)는 두께를 합산해 한 시스로 판정
- 시스 종류(표 4): 절연의 상시 최고 온도 이상이어야 한다 (XLPE 90 °C → PVC는 ST2). 자재에 ST 표기가 없으면 `확인 필요`
- 동심 도체 · 차폐선 간격: 저압은 국가 규정이라 참고로만 표시

## 자동 검사

코드나 기준값을 고친 뒤 `tools/자동검사.bat`을 더블클릭한다. Edge가 화면 없이 뷰어를 열어 아래를 확인한다.

- 케이블 모델의 판정 결과가 기준 결과(`tests/expected.json`)와 같은지
- 보고 저장 → 다시 불러오기 결과가 같은지 (설계 공정 포함), `report.json`이 열리는지
- 도면 단위 인식, 절연 부족 도면의 부적합 표시, 저압 EPR 두께 (표 7), 부속서 A 가상 직경 (3심), 잘못된 파일의 오류 안내

실패하면 무엇이 어떻게 바뀌었는지 줄마다 표시된다.

Mac에서는 `tools/자동검사.command`를 더블클릭한다. 기본 브라우저(Safari)에 검사 탭이 열리고, 결과는 터미널 창에 같은 형식으로 나온다. 검사가 끝날 때까지 그 탭은 닫지 않는다. 기준 결과 갱신은 `tools/기준결과_갱신.command`.
의도한 변경(예: 기준값을 원문대로 수정)이면 `tools/기준결과_갱신.bat`으로 기준 결과를 새로 저장한다.
미리보기 서버를 켠 상태에서 `http://localhost:8765/tests/test.html`을 열어도 같은 결과를 볼 수 있다.

## 미리보기

`미리보기.bat`(Mac은 `미리보기.command`)을 더블클릭하면 브라우저가 열린다. 창을 닫으면 종료된다.
Mac에서 게시하면 `tools/publish-push.sh`가 GitHub에 올린다 (기록: `$TMPDIR/cable-viewer-publish.log`). 안 올라갔으면 `tools/GitHub_올리기.command`.
`index.html`을 직접 열면 `report.json`을 못 읽어 보고 화면이 비어 보인다.
